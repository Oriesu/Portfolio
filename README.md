## Sobre el portfolio

Web estática desarrollada con **HTML, CSS y JavaScript**, con diseño adaptable, filtros interactivos y fichas de proyectos accesibles también sin ejecutar JavaScript.

Incluye metadatos para buscadores y para la previsualización de enlaces al compartirlos.
